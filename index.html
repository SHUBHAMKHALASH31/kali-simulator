Ye kya hai?

Ye ek pura Kali jaisa practice desktop hai — Terminal, Firefox, Files, Mousepad aur saare bade tools, sab simulated. Asli system par kuch nahi hota, isliye bina dare har command try karo.

Firefox se GitHub tool clone karna

1. Firefox kholo, address me likho github.com/sherlock-project/sherlock  2. Hara Code button dabao  3. Terminal me clone karo dabao — git clone khud chal jayega  4. Terminal me cd sherlock phir ls karke files dekho.

Baahar se download

wget https://example.com/photo.jpg — file isi folder me aa jayegi. Dobara download karoge to photo.jpg.1 banegi, bilkul asli wget ki tarah. unzip file.zip aur tar -xzf file.tar.gz se kholo.

Naya username

useradd rahul → su - rahul — prompt, home folder (/home/rahul) aur whoami sab badal jayega. Upar Settings wali window se bhi user ban sakta hai.

Photo me message (Steghide)

steghide embed -ef msg.txt -cf car.jpeg — embed aur --embed dono chalte hain. Output ka alag naam chahiye to -sf naya.jpeg lagao. Nikalne ke liye steghide extract -sf car.jpeg.

Apni file andar lao — Upload / Download

Upar ⬆ Upload, desktop ke Upload File icon, ya Files window ke Upload button se apne phone/computer ki jpg, png, txt, mp3, mp4 — koi bhi file andar lao. Wo terminal wale folder me aa jayegi: ls me dikhegi, cat file.txt se asli content padhega, photo/audio/video Files window ke preview me chalegi. Wapas lene ke liye Files me Download dabao ya terminal me download car.jpeg likho. Bina upload ke bhi har virtual file download ho jati hai. Practice ke liye andar pehle se hi car.jpeg aur msg.txt hain — audio/video chahiye to apni file upload kar do, steghide jaise tool usi par chalenge.
